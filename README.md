# CRUD con Fetch

Interfaz web **HTML + JavaScript** que realiza operaciones CRUD contra una API REST usando `fetch`. Incluye búsqueda por nombre y un modal para crear y editar registros.

## Cómo ejecutar
El archivo `db.json` está pensado para **json-server**:
```bash
npx json-server --watch db.json
```
Luego abre `index.html` en el navegador (o con Live Server).

## Proyecto de aprendizaje
Práctica de consumo de APIs REST, manipulación del DOM y eventos.
